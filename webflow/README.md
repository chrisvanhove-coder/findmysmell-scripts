# Выгрузка custom code из Webflow

Код, живущий в настройках Webflow, а не в этом репозитории.
Складывается сюда вручную, пока не настроена нормальная сборка.

| Файл | Откуда | Дата выгрузки |
|---|---|---|
| `site-custom-code.html` | Site Settings → Custom Code (квиз, общие стили) | 2026-09-11 |

## Чего ещё не хватает

- **CSS страницы результата** — правила для ~100 классов `.fms-*`. Риск R1.
- **Движок подсчёта архетипа** — то, что пишет `quiz_result` и `quiz_scores`.
  В выгруженном коде этого нет: он сохраняет только `quiz_answers`.
- **Разметка переключателя языка** — `#lang-trigger`, `#lang-dropdown`.
