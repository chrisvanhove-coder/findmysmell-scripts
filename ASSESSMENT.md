# Find My Smell — ревизия кодовой базы

Состояние на 2026-09-11, коммит `04489d3`.
Живой сайт (findmysmell.com) и превью Webflow при подготовке ревизии были
недоступны — домены блокирует egress-политика среды. Выводы сделаны по коду.

## Где живёт сайт

| Слой | Где | В git |
|---|---|---|
| Вёрстка и дизайн | Webflow Designer, пустые контейнеры `[data-result="CEO"]` | нет |
| CSS result-страницы (~100 классов `.fms-*`) | Custom code в настройках Webflow | нет |
| Логика и контент | этот репозиторий, 4 файла, ~2 900 строк | да |
| Каталог парфюма | Webflow CMS, перекрывает данные в JS | дубль |
| Сбор почты и ответов | Google Apps Script endpoint, зашит в код | нет |

Квиз (вопросы, подсчёт архетипа) в репозитории отсутствует — он в Webflow.
Контракт между квизом и результатом — четыре ключа в браузере:
`quiz_result`, `quiz_answers`, `quiz_scores`, `quiz_open`.

## Находки

**R1 — дизайн result-страницы не бэкапится.** JS создаёт элементы с классами
`.fms-*`, стили к ним лежат в custom code Webflow. В репо есть CSS для 23
классов из 122. Потеря проекта Webflow = потеря визуала без восстановления.

**R2 — FR это форк, отставший на три поколения фич.** Общего кода (без учёта
текстов) 346 строк из ~950, т.е. ~36 %. Во французской версии отсутствуют
Scent DNA, винил-плеер, texture reveal и подбор по S/R/P.

**R3 — версионирование переименованием файла.** `result47.js → result48.js`
для git это delete + create, поэтому диффов нет ни за один из 50 коммитов.

**R4 — два источника правды по парфюму.** Каталог зашит в JS и одновременно
тянется из CMS (`loadCMSPerfumes`), которая молча перезаписывает данные.
Поведение зависит от того, заполнены ли `sweet/raw/proj` в CMS.

**R5 — контент заперт в коде.** Тексты, ингредиенты, 97 URL картинок на двух
CDN, 30 hex-цветов — литералами посреди логики. Дизайн-токенов нет.

**R6 — старт по таймеру.** `setTimeout(init, 1000)` плюс ещё 200 и 300 мс на
эффекты: около секунды пустого блока, порядок не гарантирован.

**R7 — нет README, сборки, линтера и тестов.**

## Предлагаемые шаги

Не переписывать сайт с нуля. Webflow остаётся оболочкой и дизайном, весь код
result-страницы (CSS + JS) переезжает в репозиторий и подключается одним
собранным файлом.

1. **Забрать всё в репозиторий и описать.** Custom code из Webflow рядом с JS,
   README про слои, ключи storage, версию в проде и выкатку. Без изменений
   функциональности. *Нужен доступ к Webflow.*
2. **Один бандл вместо шести файлов.** EN и FR из общего кода, тексты — в
   локалях. Снимает R2 и R3.
3. **Развести контент и код.** Один источник правды для каталога, дизайн-токены
   для цветов и шрифтов. Снимает R4 и R5.
4. **Пройтись по UX.** Убрать старт по таймеру, честные состояния загрузки,
   мобильная версия, путь «квиз → результат → шеринг». Снимает R6.
